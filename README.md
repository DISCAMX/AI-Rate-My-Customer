# AI Rate My Customer

Responsive UI/UX foundation for the RateMyCustomer platform.

> **Your reputation works both ways.**

## Open the prototype

- [Interactive dashboard](./index.html)
- [Cross-platform wireframes](./platforms.html)

## Included

- Servicer and customer dashboards
- RMC Preferred benefits
- Verified Complaint Gate
- Reciprocal review QR journeys
- AI Data Exchange consent controls
- DISC, VISC, and AMDX test rewards
- iPhone, Android, iPad, smartwatch, Smart TV, and desktop wireframes

## Validate

Run `npm test` with Node.js 20 or newer.
